# CircuitTutor 产品介绍大纲

> 交互式电路模拟与解题辅助教学软件
> 一句话定位：**在浏览器里画出电路，一键求得节点电压、支路电流与解题方程，并把求解结果可视化到画布上。**

---

## 一、产品概览

### 1.1 产品定位
- 面向电路原理 / 电工基础课程的学习者与教师。
- 目标是「画图 → 求解 → 讲解」闭环：不仅给答案，还给**可读的方程与解题步骤**，服务于理解而非仅对答案。

### 1.2 目标用户与典型场景
| 用户 | 典型场景 |
| --- | --- |
| 学生 | 课后习题自检、验证手算结果、理解节点电压法 |
| 教师 | 课堂演示电路结构、串联/并联简化、对比不同参数下的结果 |
| 自学者 | 通过参数反解（已知测量值 → 求未知元件参数）巩固概念 |

### 1.3 核心价值主张
1. **零安装门槛**：一键启动本地前后端（`start.cmd`），无需安装专业仿真器（不依赖 ngspice）。
2. **所见即所得**：画布上直接呈现电势着色、电流方向流动、等电位提示。
3. **不止给结果**：输出节点电压法方程、简化步骤、解析表达式。
4. **教学容错**：电路未接地也能求解（自动选取参考节点），避免学生因画图不规范而报错卡住。

## 三、核心功能详解

### 3.1 电路编辑（F1 / F2）
- 画布基于原生 SVG 实现，不引入第三方电路绘图库。
- 元件拖动放置、引脚磁吸、导线橡皮筋预览、冗余连线拦截提示。
- 数据模型只保存「拓扑 + 布局」：导线以「元件 id + 引脚序号」的端点描述连接，移动元件不破坏连接关系。
- 交互手势：左键拖拽框选、中/右键平移、Delete 批量删除、双击空白工具切换（选择 / 手型）。

### 3.2 电路求解（F3）
- 以**网表 JSON 为唯一中间表示（IR）**，前端产出网表 → 后端求解 → 前端消费结果。
- 输出内容：节点电压、支路电流、元件吸收功率、节点电压法方程（可读字符串）、矩阵规模、参考节点标记。
- 电流符号约定：**引脚 0 → 引脚 1 方向为正**（全链路统一）。

### 3.3 符号求解（F4）
- 用 SymPy 构建符号 MNA 矩阵，输出如 `v(n1) = R2*V1/(R1+R2)` 的解析表达式。
- 支持**半符号模式**：通过网表白名单指定哪些元件保留为符号，其余代入数值。
- 防护机制：矩阵规模上限、分层化简防表达式爆炸、专用错误码（`SYMBOLIC_TOO_LARGE` / `SYMBOLIC_SINGULAR` / `UNKNOWN_SYMBOLIC`）。

### 3.4 未知量反解与测量值（F5 / F6）
- 用户勾选元件为「未知量」（画布上显示 `?`），求解器反推其参数值。
- 结果分两类：**已确定**（给出数值）与**条件不足**（列出无法唯一定量的参数）。
- 支持追加测量约束：支路电流、节点电势、两节点电势差，用于补足方程。

### 3.5 自动简化与等效（F7）
- 识别串联链（R1-R2-R3）与并联组（R1∥R2∥R3），输出可点击的简化步骤与合并后阻值预览。
- 戴维南等效：指定端口，输出开路电压与等效内阻。

### 3.6 教学可视化（F8 / F9 / F10）
- **电势着色**：电压映射为蓝→红渐变，采用分位数映射避免颜色挤堆，非法值回退中性色。
- **电流流动**：橙色流线与方向箭头，与电压色谱视觉解耦，避免语义冲突。
- **等电位提示**：拖拽导线端点到等电位点时高亮节点并提示「等效电位点，可连接」，防止冗余连线。
- 画布叠加层分区：左上提示、左下图例、右下电势图例、右上工具栏。

## 四、使用流程

1. 双击 `start.cmd`（或分别启动后端 uvicorn `:8000` 与前端 Vite `:5173`）。
2. 从左侧元件库拖出元件、拉线连接，形成电路。
3. 在右侧属性面板设置元件数值；需要反解时勾选「未知量」。
4. 点击「求解电路」→ 右侧抽屉展示节点电压、支路电流 / 功率、方程。
5. 可选：点击「识别串/并联」查看简化步骤；输入测量值辅助反解。
6. 保存工程或导出网表 JSON 用于分享 / 二次开发。

## 五、技术架构

### 5.1 总体架构

```
┌─────────────────────────┐        ┌─────────────────────────┐
│  frontend/ (React+TS)   │  网表    │  backend/ (FastAPI)     │
│  画布编辑 / 可视化       │ ──────▶ │  MNA 数值 / 符号 / 反解  │
│  store.ts 单一状态源     │ ◀────── │  简化 / 戴维南           │
└─────────────────────────┘ {ok,data,error} └───────────────────┘
```

### 5.2 关键设计约定
- 网表 JSON 是前后端唯一 IR；**符号计算一律在后端**，前端不做符号运算。
- 所有接口统一返回 `{ok, data, error}`，业务错误以 HTTP 200 + `ok=false` + 错误码返回。
- 等电位判定单一来源：`topology.ts` + `utils/unionFind.ts`，界面与网表共用。
- 求解器为纯函数，便于单测；无接地时自动选取参考节点。

### 5.3 技术栈
| 层 | 选型 |
| --- | --- |
| 前端 | React + TypeScript + Vite 8 + Vitest 5，原生 SVG 渲染 |
| 后端 | Python 3.14 + FastAPI + numpy（数值） + SymPy（符号） |
| 运行 | Windows 一键脚本 `start.cmd`，双服务分窗口启停 |

### 5.4 接口一览
| 接口 | 作用 |
| --- | --- |
| `GET /health` | 服务探活 |
| `POST /solve_dc` | 直流数值求解 |
| `POST /solve_symbolic` | 符号 / 半符号求解 |
| `POST /solve_unknowns` | 未知量反解（可附测量值） |
| `POST /simplify` | 串/并联简化步骤 |
| `POST /thevenin` | 戴维南等效 |

## 六、质量保障

- **前端单测**：9 个测试文件、74 项用例（网表、等电位、颜色映射、几何、主题、吸附、工程读写等）。
- **后端测试**：47 项用例（数值求解 16、符号求解 9、简化 11、未知量反解 11）。
- 误差约定：数值解断言容差 1e-6；奇异矩阵返回明确错误而非静默失败。

---

## 七、适用边界与当前限制

- 仅支持**直流线性电路**，暂不含正弦稳态、瞬态与非线性器件（二极管/三极管/数字逻辑）。
- 不引入 ngspice 等外部仿真内核，求解能力由项目自研 MNA 提供。
- 符号求解规模受矩阵上限约束，超大电路建议切半符号或数值模式。
- 元件类型支持范围以网表 schema 为准，扩展新元件需前后端同步。

---

## 八、后续规划方向（建议）

1. **能力扩展**：正弦稳态（复数 MNA / 相量）、一阶瞬态（RC/RL）、非线性器件（分段线性 + 牛顿迭代）。
2. **教学闭环**：分步解题报告导出（含符号推导与简化过程）、习题库与作答校验。
3. **体验增强**：符号求解结果前端展示、求解历史对比、多方案参数扫描。
4. **协作与分享**：工程云端存储、电路链接分享、只读演示模式。

## 附录：术语表

| 术语 | 含义 |
| --- | --- |
| 网表（Netlist） | 描述电路节点与元件连接关系的 JSON 数据，前后端唯一 IR |
| MNA | 改进节点电压法（Modified Nodal Analysis），支持电压源与受控源 |
| 半符号模式 | 仅指定元件保留为符号、其余代入数值的求解方式 |
| 未知量反解 | 已知部分测量结果，反推被标记为未知的元件参数 |
| 等电位点 | 电气上属于同一节点的多个点，连接不改变电路语义 |
| 戴维南等效 | 将二端网络等效为「电压源 + 串联电阻」 |
