```text

要求：
1. 每页只讲一个观点，标题必须是一句「结论式短句」（不超过 20 字），不要用「功能介绍」这类空标题。

3. 每页给出：页面标题 / 正文要点 / 图位占位说明 / 演讲者备注（60-100 字）。
4. 【最重要】凡本文档标注「图位」的地方，一律留出空白占位框，不要画任何软件界面、不要画任何电路仿真结果，

5. 视觉风格：教学工具感、技术简洁风。主色深蓝 #1E3A8A，强调色橙 #F97316（对应产品里"电流"的颜色），
   中间调灰蓝 #94A3B8，浅底 #F8FAFC。少用渐变与阴影，多用线框与网格背景隐喻"电路画布"。
6. 不要出现任何未在本简报中给出的数据；不要夸大产品能力，最后一页前的"边界"页必须保留。
7. 输出格式：先输出目录，再逐页输出；同时在最后附一份 Marp 或 Slidev 可用的 Markdown 源码。
```

## 二、一句话产品定义

**CircuitTutor 是一款浏览器内的交互式电路模拟与解题辅助教学软件：画出电路，一键求解，并把电压、电流、方程直接可视化成"能看懂的解题过程"。**

关键词（封面选 4 个即可）：`画图即仿真` `给出方程不只给答案` `无地也能解` `零安装`

## 三、受众与叙事策略

| 项 | 说明 |
| --- | --- |
| 主要受众 | 高校电路/电工课程教师、教学管理者；次要为电子类专业学生 |
| 受众关心的问题 | 学生会不会用？是否真的帮助理解原理？部署难不难？技术是否可靠？ |
| 叙事主线 | 痛点 → 定位 → **第一部分 功能（编辑 / 求解 / 可视化 / 步骤）** → 差异化 → **第二部分 技术（架构 / 算法 / 契约与质量）** → 边界 → 展望 |
| 演讲时长 | 10-12 分钟（18 页，平均 40-45 秒/页） |
| 两部分配比 | 功能 8 页（P5-P12，含扉页），技术 5 页（P13-P16，含扉页），功能是主体、技术是背书 |
| 情绪曲线 | 前 2 页共情痛点 → 功能段密集输出价值 → 技术段建立信任 → 边界段体现诚实 → 展望收束 |

**两部分的分工（务必让模型理解）：**

- **第一部分 功能介绍**：讲"老师/学生能拿它做什么"，主角是**配图演示**，每页至少一块图位；
- **第二部分 技术介绍**：讲"它凭什么做得到、凭什么可信"，主角是**结构图与流程可视化**，允许出现公式与代码片段。

## 四、图示规范（所有页面通用）

| 项 | 规定 |
| --- | --- |
| 图位标注 | 每个占位框左上角标图号，框内写「图号 · 内容说明 · 建议尺寸」 |
| 图号体系 | `A` = 真实截图（人工贴入，模型必须留空）；`B` = 示意图（模型可画）；`T` = 技术可视化图（模型可画） |
| 占位框样式 | 浅灰 `#CBD5E1` 1.5pt 虚线、填充 `#F8FAFC`、圆角 8px、内部居中文字 14pt 灰蓝 |

| 图注 | 图下方 12pt 灰字，格式「图 5-1 连线吸附与等电位提示」 |
| 页内图文比例 | 功能介绍页：图 ≥ 50% 版面；技术介绍页：图或表 ≥ 40% 版面 |

## 五、页面清单（逐页脚本）

### P1 · 封面
- **标题**：CircuitTutor —— 画出来的电路，讲得清的答案

- **标题**：会算题，不等于懂电路
- **要点**
  1. 手算一步错，全盘重来，看不到错在哪
  2. 专业仿真器只给数值，给不出可读方程
  3. 安装重、界面专业，课堂用不起来
  4. 老师改参数、对比结果全靠重复劳动
- **图位 B1**：左右对比情绪图（草稿纸红叉 vs 抽象仿真界面）· 下方横向 100%×35% · 建议 1600×500px

### P3 · 产品定位
- **标题**：从"对答案"到"看推导"的教学闭环
- **要点**
  1. 画图 → 求解 → 讲解，三步闭环
  2. 结果不只是数值，还有节点电压法方程
  3. 同一画布同时呈现电压与电流的物理图像
  4. 本地零安装，双击脚本即可启动
- **图位 B2**：三步流程箭头图 · 中部横向 100%×40% · 建议 1600×560px
- **备注**：这是全篇的"电梯陈述"，后面所有页都是它的展开。

### P4 · 能力全景（承上启下）

  2. **求解**：数值、符号、未知量反解
  3. **可视化**：电势着色、电流流动、等电位提示
  4. **运行**：前后端分离、一键启动、单元测试
- **图位 B3**：四象限能力矩阵 · 右侧 55% 宽 · 建议 1000×780px
- **备注**：此页只讲结构不展开，并明确告知"下面进入第一部分，逐个打开这四块"。

## 第一部分 · 功能介绍（P5-P11）

### P5 · 章节扉页
- **标题**：第一部分 · 功能：它能让课堂发生什么变化
- **正文**：本部分含 6 页，每页一个核心功能，均配真实界面演示图
- **图位**：无需配图（可用 P1 的 A1 做极淡背景水印，透明度 ≤ 8%）
- **备注**：扉页停留不超过 5 秒，直接进入 P6。

### P6 · 功能一：电路编辑
- **标题**：拖一拖就画对，改完立刻生效
- **要点**
  1. 10 类元件：电阻、源、四种受控源、运放、开关、接地
  2. 导线按"引脚引用"建模，移动元件不断线
  3. 支持折点连接点、线段任意位置吸附
  4. 框选批量删除、清空与编号重置
- **图位（三图并排，等高）**
  - **A2**：左侧元件库全貌（含 10 个元件图标）· 左栏 32% · 建议 640×480px
  - **A3**：拖拽连线中的磁吸高亮 · 中栏 32% · 建议 640×480px
  - **A4**：等电位提示气泡 · 右栏 32% · 建议 640×480px
- **备注**：强调"容错设计"——学生画得随意，工具替他兜住。

### P7 · 功能二：数值求解
- **标题**：一键出结果，还附一份看得懂的方程
- **要点**
  1. 输出节点电压、支路电流、元件功率
  2. 同步给出节点电压法方程，可逐步对账
  3. 标注矩阵规模与参考节点
  4. 无接地自动选参考，画图不规范也能算
- **图位 A5**：求解结果抽屉（含矩阵规模、电压、电流/功率、方程列表）· 右侧 52% 宽 · 建议 980×900px
- **图注**：图 7-1 求解结果与节点电压法方程
- **备注**：这一页是全篇"可信度"的第一根支柱，务必让评委看清方程文字。

### P8 · 功能三：符号求解
- **标题**：不只给数字，还能给公式
- **要点**
  1. 全符号求解，输出解析表达式
  2. 支持半符号：指定哪些元件保留为符号
  3. 表达式自动分层化简，避免爆炸
  4. 例：运放增益 `v(vo) = -R2·V1/R1`
- **图位 B4**：三种求解能力对照卡片（数值 / 符号 / 反解）· 下半区 100%×45% · 建议 1600×620px
- **补充占位（重要）**：图位下方留一块**公式展示区**（浅蓝底 `#EEF2FF`、等宽字体、18pt 居中）：
  `v(vo) = -R2 · V1 / R1`　→　半符号（仅 R2 为符号）：`v(vo) = -R2 / 1000`
- **备注**：**不要放符号求解的界面截图**——该能力目前是后端接口，前端暂无展示面板。

### P9 · 功能四：未知量反解
- **标题**：已知结果，反推未知的元件参数
- **要点**
  1. 勾选元件为未知量，画布显示 `?`
  2. 求解器反推参数值，直接给出电阻阻值
  3. 可补测量值：支路电流 / 电势 / 电势差
  4. 条件不足时明确列"无法唯一定量"
- **图位 A6**：画布 R2 显示 `?` + 反解结果区 · 左侧 50% 宽 · 建议 940×760px
- **图位（并列）**：右侧放一张**结果对照卡**（模型可直接排版，非截图）
  - 无测量值 → `resolved = false`，R2 属于 undetermined
  - 加 `V(n1) = 1.25 V` → `R2 = 333.3 Ω`，`resolved = true`
- **备注**：演示电路 β（5V 分压 + 未知 R2）。讲"工具会诚实地说条件不足"。

### P10 · 功能五：教学可视化
- **标题**：电压是颜色，电流是会动的箭头
- **要点**
  1. 节点电势映射蓝→橙红渐变色，配图例
  2. 电流用橙色流线 + 方向箭头表示
  3. 拖线时提示"等电位点，可连接"
  4. 悬停节点即读电势，不必翻结果面板
- **图位 A7**：电势着色 + 电流流线同屏截图（浅色主题）· 主体 58% 宽 · 建议 1100×860px
- **图位 B5**：电压色谱与流线说明小图 · 右下 36% · 建议 620×300px
- **备注**：视觉上必须让"颜色=电压、流线=电流"一眼可分，避免语义混淆。

### P11 · 功能六：自动简化与等效
- **标题**：像老师一样，把该合并的先合并
- **要点**
  1. 自动识别串联链与并联组，给出合并过程
  2. 步骤可点击，画布上对应元件同步高亮
  3. 戴维南等效：指定端口得开路电压与内阻
  4. 例：R2+R3 合并 3kΩ，端口等效 7.2V / 600Ω
- **图位 A8**：简化步骤列表 + 画布高亮联动 · 左侧 46% 宽 · 建议 900×820px
- **图位 B6**：串并联化简前后对照 · 右侧 48% · 建议 940×700px
- **备注**：演示电路 γ。这页对教师最有说服力——备课演示直接可用。

### P12 · 差异化定位
- **标题**：比仿真器懂教学，比手算更直观
- **要点**
  1. vs SPICE：不装内核、给方程、界面为教学设计
  2. vs 手算：即时反馈、可视化、可反复试参数
  3. vs 在线计算器：可画图、可存工程、有推导步骤
  4. 独有能力：符号 + 反解 + 电势可视化三合一
- **图位 B7**：三列对比表（表格排版即可，可不出图）· 中部 100%×55% · 建议 1600×820px
- **备注**：避免贬低竞品，只谈定位差异。这是功能部分的收尾。

## 第二部分 · 技术介绍（P13-P16）

### P13 · 章节扉页
- **标题**：第二部分 · 技术：它凭什么算得对、改得动
- **正文**：架构边界 / 求解管线 / 契约与质量，共 4 页，每页至少一张结构可视化图
- **图位**：无需实拍图（可用 B8 架构图极淡版本作背景，透明度 ≤ 8%）
- **备注**：转场台词——"前面讲它能做什么，接下来讲它凭什么做得到。"

### P14 · 技术一：整体架构
- **标题**：网表是唯一语言，求解全权交给后端
- **要点**
  1. 前后端以网表 JSON 为唯一中间表示（IR）
  2. 前端只负责画与渲染，不做任何符号计算
  3. 后端 MNA 数值 / SymPy 符号双引擎
  4. 等电位判定单一来源，界面与网表结论一致
- **图位 B8**：左右双框架数据流图（请求网表 JSON / 响应 {ok,data,error}）· 上部 100%×52% · 建议 1600×720px
- **图位 A9**：导出的网表 JSON 片段截图（nodes / components / pins 字段）· 下部左侧 42% · 建议 760×420px
- **图位 T1**：前端画布状态 ⇄ 后端网表 IR 对照 · 下部右侧 54% · 建议 900×420px
- **备注**：面向懂技术的评委，重点讲"为什么这样切"——求解逻辑集中才可验证。

### P15 · 技术二：求解管线与双引擎
- **标题**：五步求解，一套 stamp 规则供两个引擎
- **要点**
  1. 校验网表 → 选参考节点 → 组装 A·x=b
  2. 求解线性方程组 → 回流电流、功率、方程
  3. 数值用 numpy，符号用 SymPy，共用 stamp 规则
  4. 矩阵奇异、规模超限均有专用错误码
- **图位 T2**：MNA 五步求解管线（竖向管线 + 符号模式分叉）· 左侧 46% 宽 · 建议 900×900px
- **图位 T3**：双引擎共用元件印章表 · 右侧 50% · 建议 980×760px
- **备注**：这页是全篇技术含量最高处，允许出现 A/b 矩阵与 stamp 术语，但每条要点仍要口语化。

### P16 · 技术三：契约、错误与质量
- **标题**：接口统一契约，错误都能读懂
- **要点**
  1. 所有接口返回 `{ok, data, error}`
  2. 业务错误以 `ok=false` + 错误码返回
  3. 前端 74 项、后端 47 项测试用例守护
  4. 求解器为纯函数，可独立验证、可回归
- **图位 T4**：错误码 → 用户提示对照表 · 左下 44% · 建议 860×520px
- **图位 A10**：前后端测试通过截图（74 passed / 47 passed）· 右侧 52% · 建议 980×620px
- **备注**：诚实说明这是教学规模项目，但强调工程纪律；错误可读是教学产品的底线。

## 六、结尾部分（P17-P18）

### P17 · 边界与诚实
- **标题**：先把直流做扎实，再谈更多

  3. 符号求解受矩阵规模上限约束
  4. 自研求解内核，不依赖 ngspice

- **要点**

  2. 教学：分步解题报告导出、习题库与校验
  3. 体验：符号解前端展示、参数扫描对比
  4. 协作：工程云存储、链接分享、演示模式
- **图位 B11**：四层台阶路线图 · 中部 100%×50% · 建议 1600×700px
- **收尾句**：让每一次"算错了"，都变成一次看得见的理解。
- **备注**：以情感收束，回到 P2 的痛点，形成闭环。
