# CircuitTutor 配套素材与演示设计说明

> **本文档用途**：配合 `CircuitTutor-PPT生成简报.md` 使用。它解决三件事：
> 1. **配图索引**：PPT 每一页该放什么图、放在什么位置、由谁生成（实时截图 / 大模型画示意图 / 本人绘矢量图）；
> 2. **可视化演示提示词**：把可直接复制的提示词交给其它大模型，产出功能演示图与技术可视化图；
> 3. **演示电路设计**：给出 3 个能一次性覆盖产品绝大多数能力的示范电路，并说明每个电路"演示什么、怎么演示"。
>
> 文中所有数值均已通过后端接口实测得到，可直接写进 PPT 与讲稿（复算方式见第 6 节）。

---

## 1. 素材总览与图片来源分类

| 代号 | 类型 | 生产方式 | 适用场景 | 保真度 |
| --- | --- | --- | --- | --- |
| **A** | 实时真图 | 启动产品后用浏览器截图 | 各项功能的"有图有真相" | 最高，推荐 |
| **B** | 示意图 | 大模型按提示词生成 SVG/图片 | 流程、架构、对比、叠层关系 | 中，需人工核对 |
| **C** | 矢量重绘 | 按本文第 4 节的电路数据自行绘制 | 演示电路的结构图、简化前后对照 | 高 |

**配图优先级原则**：能截真图就不画示意图；一旦用 B 类图，必须在图角标注"示意图，非真实截图"，避免误导评委。

**配色沿用 PPT 简报**：深蓝 `#1E3A8A`、强调橙 `#F97316`（电流/关键动词）、灰蓝 `#94A3B8`（导线/辅助线）、浅底 `#F8FAFC`；电势渐变为**蓝 → 灰蓝 → 橙红**（低电势到高电势）。

## 4. 演示电路设计（3 个电路覆盖全部卖点）

设计目标：**三个电路就讲完产品**。α 讲"求与看"，β 讲"反推"，γ 讲"化简与等效"。所有数值均为后端实测结果，可现场复算。

### 4.1 演示电路 α · 理想运放反相放大（主力电路）

**用途**：P1 封面主视觉、P5 编辑演示、P6 数值求解、P7 可视化、P10 技术架构（矩阵规模）。

**电路结构**

```
            R1=1kΩ        R2=10kΩ
  V1(1V) ┌────/\/\/────┬────/\/\/────┐
    (+)  │             │             │
    ─────┤ vin       (vn)            ├──── vo
    (−)  │             │      ┌──────┘
    g ───┘             └──────┤ −\
                              │   >──┘
                        g ────┤ +/
                              OP1（理想运放）
```

**元件清单**

| 元件 | 类型 | 引脚连接 | 数值 |
| --- | --- | --- | --- |
| V1 | 独立电压源 | vin → g | 1 V |
| R1 | 电阻 | vin — vn | 1 kΩ |
| R2 | 电阻 | vn — vo | 10 kΩ |
| OP1 | 理想运放 | in+ = g，in− = vn，out = vo | — |

**实测结果**

| 量 | 数值 |
| --- | --- |
| v(g) | 0 V |
| v(vin) | 1 V |
| v(vn) | 0 V（虚地） |
| v(vo) | **−10 V** |
| i(R1) = i(R2) | 1 mA |
| P(R2) | 10 mW |
| 矩阵规模 | 5×5 |
| 符号解（全符号） | `v(vo) = -R2*V1/R1` |
| 半符号（仅 R2 保留符号） | `v(vo) = -R2/1000` |

**演示路径（把能力挂到画面上）**

| 能力 | 怎么演示 | 讲什么 |
| --- | --- | --- |
| 编辑 | 用「理想运放」+ 两只电阻 + 一只电压源搭出来；把 R2 拖远一点，导线自动跟随 | 移动元件不断线，因为导线引用的是引脚 |
| 数值求解 | 点「求解电路」，抽屉里出现 5×5 矩阵的节点电压法方程 | 方程是给人看的，不只是给机器算的 |
| 虚地概念 | 在画布上看 vo 与 vn 的颜色差异极大 | vn 电势为 0 却不在接地网络里——"虚地"一眼可见 |
| 符号求解 | 讲稿中给出 `-R2·V1/R1`，并说明半符号可只让 R2 保留符号 | 换增益只改 R2，公式立刻可交给学生 |
| 放大倍数 | 画布上 R1/R2 的电流流线同向同密度，vo 处颜色最深（负电压） | 电流相同、电压反相，运放"虚短虚断"直观可见 |

**现场改动建议**：把 R2 从 10 kΩ 改成 20 kΩ，重算，vo 从 −10 V 变 −20 V，颜色更深（受色阶钳制时为最饱和端）。这是全篇最有冲击力的一次交互，建议放慢节奏讲。

### 4.2 演示电路 β · 未知电阻反解（教学最强）

**用途**：P6 未知量反解、P12 "探究"场景。

**电路结构**

```
   V1(5V)        R1=1kΩ        R2=?
    (+)  ┌────────/\/\/────────┬
    ─────┤ na                  n1 ──── 测量值 V(n1)=1.25 V
    (−)  │                     │
    g ───┘                     └── R2（标记为未知量，画布显示 ?）
```

**元件清单**

| 元件 | 类型 | 引脚连接 | 数值 |
| --- | --- | --- | --- |
| V1 | 独立电压源 | na → g | 5 V |
| R1 | 电阻 | na — n1 | 1 kΩ |
| R2 | 电阻 | n1 — g | **未知量**（勾选"未知"） |

**演示路径**

1. 先不填任何测量值，直接点「求解未知量」→ 结果是 `resolved = false`，R2 进入 `undetermined`；
   → 讲："方程不够，工具会诚实地说'条件不足'，而不是编一个数。"
2. 添加测量值 `V(n1) = 1.25 V`，再求解 → **R2 = 333.3 Ω**，`resolved = true`；
   → 讲："这就是习题里'已知电势求电阻'的场景，学生可以自己造题。"
3. 教学延伸（口头，不必演示）：把测量值改成 `1 V`，反出 R2 = 250 Ω；改成 `2.5 V`，反出 R2 = 1 kΩ。

**配套双未知量版本**（口述备用）：V1=12 V，R1 未知、R2 未知、R3=2 kΩ 接地；给两条测量 `V(n1)=9 V`、`V(n2)=6 V` → 解得 **R1 = R2 = 1 kΩ**；若只给一条测量，则 R1、R2 均为 undetermined。这个对比用来解释"方程数与未知数"的关系，非常适合课堂提问。

### 4.3 演示电路 γ · 混联网络 + 戴维南等效

**用途**：P8 自动简化、P6 戴维南、P10 架构（同一网表供多个接口）。

**电路结构**

```
                R1=1kΩ
   V1(12V) ┌────/\/\/────┬── nb ──┬──── R4=3kΩ ────┐
     (+)   │             │        │                │
     ──────┤ na          │        └── R2=1kΩ ── nc ─ R3=2kΩ ── g
     (−)   │             │                         │
     g ────┴─────────────┴─────────────────────────┘
                                    端口 (nb, g) → 戴维南等效
```

**元件清单**

| 元件 | 类型 | 引脚连接 | 数值 |
| --- | --- | --- | --- |
| V1 | 独立电压源 | na → g | 12 V |
| R1 | 电阻 | na — nb | 1 kΩ |
| R2 | 电阻 | nb — nc | 1 kΩ |
| R3 | 电阻 | nc — g | 2 kΩ |
| R4 | 电阻 | nb — g | 3 kΩ |

**实测结果**

| 量 | 数值 |
| --- | --- |
| v(na) / v(nb) / v(nc) | 12 V / 7.2 V / 4.8 V |
| i(R1) / i(R2) / i(R3) / i(R4) | 4.8 mA / 2.4 mA / 2.4 mA / 2.4 mA |
| 简化第 1 步 | 「串联电阻 R2 + R3」→ 中间节点 nc 仅连接链内电阻，合并为 **3 kΩ** |
| 戴维南端口 (nb, g) | **Vth = 7.2 V，Rth = 600 Ω** |
| 校验 | 3 kΩ ∥ 3 kΩ = 1.5 kΩ，与 R1 分压：12 × 1.5/2.5 = **7.2 V** ✓；Rth = 1 kΩ ∥ 1.5 kΩ = **600 Ω** ✓ |

**演示路径**

1. 求解 → 三个节点电压分别是 12 / 7.2 / 4.8 V，**三档颜色**（高→中→低）在同一画布上清晰分层；
2. 点「识别串/并联」→ 出现第 1 步；点击该步骤，画布上 R2、R3 同步高亮；
3. 讲："工具不只是替你算，它把'这一步该合并谁'指出来，学生可以跟着做。"
4. 戴维南结果与手算校验一致 → 讲："等效不是黑盒，数字对得上。"
